ts is a basic game, with a simple but co-op or versus mechanics , ideal for the boredom
The ball is passed back and forth over the net, and whoever lets it drop loses (unfortunately, this version doesn't include a scoring system—it’s like DLC. ok not).

## controls
player 1: a=left d=right w=jump
player 2: up-arrow=salto left-arrow=left right-arrow=right
